# Vipan Shop - E-commerce Platform

A modern, full-stack e-commerce web application featuring a beautiful user interface and a robust backend API.

## Features
*   **Dynamic Product Catalog:** View products with categories, pricing, and images.
*   **Shopping Cart:** Add, remove, and manage items in your cart.
*   **User Authentication:** Secure registration and login system using JWT tokens.
*   **Checkout System:** Calculates totals, GST, and delivery fees.
*   **Modern UI:** Features a custom cursor, dark mode aesthetics, and smooth animations.

## Tech Stack
*   **Frontend:** Vanilla JavaScript, HTML5, CSS3
*   **Backend:** Python, Django, Django REST Framework
*   **Database:** SQLite / PostgreSQL
*   **Authentication:** JWT (JSON Web Tokens)
